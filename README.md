## Proyectos destacados

### [BanchoXterm](https://banchoxterm.gargadonapps.com)

**Terminal multiprotocolo y administrador de sesiones remotas para Linux y Windows.**

Reúne el acceso a equipos remotos y la gestión de archivos en una misma interfaz, con sesiones organizadas y herramientas para administración de sistemas.

- Terminales en pestañas; conexiones SSH, Telnet y consola serie.
- Explorador SFTP, transferencias FTP/FTPS y gestión de archivos remotos.
- Túneles SSH, registro de sesiones y monitoreo remoto.

**Áreas técnicas:** protocolos de red · emulación de terminal · integración con el sistema operativo · interfaces multiplataforma

[Visitar BanchoXterm →](https://banchoxterm.gargadonapps.com) · [Ver código y documentación →](https://github.com/Gargadon/banchoxterm)

### [Libria](https://getlibria.org)

**Entorno de escritorio para escribir, revisar y maquetar libros.**

Integra el flujo editorial desde el borrador hasta la publicación digital o impresa, con edición estructurada y control sobre la presentación final.

- Edición por bloques, organización de capítulos y fichas de personajes y lugares.
- Configuración tipográfica y previsualización para papel y dispositivos de lectura.
- Importación de DOCX y TXT; exportación a EPUB, PDF y DOCX.
- Formato de proyecto abierto `.libria` y herramientas de revisión editorial.

**Tecnologías:** TypeScript · Angular · Tauri · Rust · Vivliostyle  
**Áreas técnicas:** gestión de estado · modelado de documentos · composición tipográfica · interoperabilidad de formatos

[Visitar Libria →](https://getlibria.org) · [Ver código y documentación →](https://github.com/Gargadon/libria)

### [Proclama](https://proclama.gargadonapps.com)

**Presentador multimedia para iglesias y congregaciones.**

Separa la interfaz del operador de la salida de proyección y reúne el contenido necesario para organizar y conducir un servicio.

- Proyección de canciones, versículos bíblicos, imágenes y videos.
- Organización del servicio e importación de documentos PDF.
- Control remoto desde teléfonos y tabletas mediante un servidor HTTP integrado.

**Tecnologías:** C++ · Qt 6 · CMake  
**Áreas técnicas:** multimedia · múltiples pantallas · control remoto web · integración nativa

[Visitar Proclama →](https://proclama.gargadonapps.com) · [Ver código y documentación →](https://github.com/Gargadon/Proclama)
